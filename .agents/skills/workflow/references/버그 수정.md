# 버그 수정

1. [debug](../../debug/SKILL.md)에서 기존 계약, 기대 결과, 실패 조건을 찾는다. 기존 로그나 테스트에서 충분한 증거를 확인하면 그 증거를 사용한다. 로컬에서 재현이 필요하면 수정 범위에 맞는 최소 검사를 선택한다.
2. [implement](../../implement/SKILL.md)로 실패 원인을 수정한다. 문제를 고치려면 합의된 공개 API 계약을 변경해야 하는지 확인한다. 계약의 변경 결정이 남아 있으면 그 결정에 의존하는 수정 부분을 보류한다.
3. [test](../../test/SKILL.md)로 원래 실패 조건을 회귀 시나리오에 포함한다. 서로 다른 실패가 같은 상태 코드를 반환하면 의도한 원인도 확인한다. 변경 후 같은 조건으로 검증한다.
4. 변경 범위와 실패 원인, 실제 검사 결과를 검토한다. 수정 전 실패나 수정 후 성공을 확인하지 못했다면 해당 결과를 미검증으로 적는다.
