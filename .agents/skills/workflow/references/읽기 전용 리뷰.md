# 읽기 전용 리뷰

1. [self-review](../../self-review/SKILL.md)로 요청한 범위와 비교 기준을 확인한다. 파일, 포맷, Git 상태를 그대로 둔다.
2. 발견 사항마다 실제 발생 조건, 영향, 근거, 수정안을 적는다. 확인이 필요한 의심은 그 상태로 표시한다.
3. 사용자가 기존 CI 결과도 요청하면 [verify](../../verify/SKILL.md)로 대상 SHA의 실행을 조회한다. 사용자가 특정 테스트 실행을 함께 요청하면 그 테스트를 소스 수정 없이 실행한다. 포맷 적용 등 소스를 바꾸는 부수효과를 피할 방법이 없으면 이유를 보고한다.
4. 지적 사항과 검사 증거를 보고한다. 발견한 결함이 없으면 확인한 범위를 밝힌다.
