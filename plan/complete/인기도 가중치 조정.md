# Plan: 인기도 가중치 조정

## Overview

운영 데이터 분포에서 시간 조회가 누적 평점·PICK·참여보다 과도하게 큰 영향을 주는 문제를 완화한다. 인기도 계산 구조와 정규화 기준은 유지하고, 네 축의 전역 가중치만 관심도 5%, 평가도 35%, 선호도 20%, 참여도 40%로 조정한다.

### Assumptions

1. 이번 변경은 가중치 조정만 포함한다.
2. HOUR/WEEK/MONTH 정규화 기준값 50/100/200/300은 유지한다.
3. 조회 중복 방지와 급상승·누적 인기 분리는 후속 범위다.
4. 변경 가중치는 HOUR/WEEK/MONTH에 공통 적용한다.
5. 기존 Snapshot을 재계산하지 않고 배포 이후 생성되는 Snapshot부터 적용한다.
6. 데이터베이스 스키마와 API 계약은 변경하지 않는다.

### Success Criteria

1. 인기도 가중치는 관심도 0.05, 평가도 0.35, 선호도 0.20, 참여도 0.40이며 합계는 1.00이다.
2. 조회 1건의 최종 점수 기여는 0.0010이고, 관심도 단독 최대 기여는 0.0500이다.
3. 설정 기본값과 실제 Batch 설정이 동일하며 관련 테스트가 새 비율을 검증한다.
4. GitHub PR CI의 필수 검사가 모두 통과한다.

### Impact Scope

- 대상 모듈: `bottlenote-batch`
- 대상 영역: 인기도 관측 설정과 설정 검증 테스트
- 스키마 변경: 없음
- API 변경: 없음
- 기존 Snapshot 보정: 없음
