# ADR (Architecture Decision Records)

코드와 git 히스토리에서 복원되지 않는 결정을 기록한다. 계획·진행 상태는 여기에 두지 않는다. 진행 추적은 workspace 이슈와 PR 본문이 담당한다.

## 작성 규칙

- 파일명: `YYYY.MM.DD 결정을 한 문장으로.md`. 날짜는 결정일이며 하이픈을 쓰지 않는다.
- 헤더: 상태(제안됨 / 승인됨 / 적용됨 / 대체됨), 결정일, 대상 모듈, 관련 이슈·PR.
- 본문: 결정, 배경, 선택하지 않은 대안, 결과와 비용. 필요하면 개정 이력 표를 헤더 아래 둔다.
- 결정이 바뀌면 기존 문서를 지우지 않고 상태를 `대체됨`으로 바꾸고 새 문서를 가리킨다. 작은 조정은 개정 이력에 추가한다.
- 2026.09.07 이전 문서는 `plan/` 계획서에서 결정 부분만 추린 것이다. 원본은 각 문서의 "원본 계획" 항목과 git 히스토리로 찾는다.
