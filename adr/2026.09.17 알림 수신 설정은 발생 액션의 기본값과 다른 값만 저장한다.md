# 알림 수신 설정은 발생 액션의 기본값과 다른 값만 저장한다

- Decision Date(결정일): 2026.09.17
- Scope(대상): Notification 발생 액션, 사용자 수신 설정, 기존 알림 생성 경로
- Related Issues(관련 이슈): bottle-note/workspace#465

## Context(배경)

기존 category와 클릭 Action은 리뷰 댓글과 답글을 구분하지 못한다. 화면 그룹으로 일괄 설정하면서 개별 발생 액션도 설정해야 한다. 사용자마다 전체 종류의 행을 생성하면 종류 추가마다 기존 사용자의 설정을 채워야 한다.

## Decision(결정)

`NotificationEventAction`이 `NotificationSettingGroup`, 설명, `defaultEnabled`를 소유한다. 프로그램을 포함한 5개 그룹·20개 발생 액션을 정의하고 `user_notification_settings`에는 `(user_id, action_code)`별 기본값과 다른 값만 저장한다. 설정이 없으면 enum 기본값을 적용하고, 기본값으로 복원하면 행을 삭제한다. 변경 저장은 유일 키를 이용한 원자적 upsert로 처리한다.

신규 Notification은 발생 액션을 반드시 지정하고 저장 전 사용자별 유효 수신값을 확인한다. 거부는 신규 알림 저장만 차단하며 기존 알림을 삭제하지 않는다. `notifications.event_action`에는 발생 액션을 저장한다. 과거 행은 원본 유형이 REVIEW_LIKE/FOLLOW/HELP_ANSWER인 경우만 해당 발생 액션으로 변환한다. 구분할 근거가 부족한 댓글·답글 등은 임의로 분류하지 않고 NULL로 보존한다.

발생 분류인 `NotificationSourceType`은 제거한다. 단, 기존 `(source_type, source_id, user_id)` 중복 방지 키는 유지하고 댓글·답글 모두 기존 원본 유형 문자열 `REVIEW_REPLY`를 사용한다. 이 호환 키와 세부 수신 설정 액션은 목적이 다르다. `NotificationCategory`/`NotificationType`도 제거하고 목록 필터를 `eventActions`/`groups`, 응답을 `eventAction`/`group`으로 전환한다. 같은 필터의 값들은 OR, 두 필터 사이는 AND로 적용한다. 그룹은 액션에서 계산하며 DB에 중복 저장하지 않는다. 과거 미분류 알림은 전체 조회에서 유지하되 분류 필터에서는 제외한다. 이전 커서는 조회 문맥 버전을 변경해 거부한다. 클릭 이동의 `NotificationActionType`은 유지한다.

모바일 푸시 설정, 마케팅 동의, 신규 발생처, 설정 HTTP API는 이 변경 범위에서 다루지 않는다.

## Status(상태)

Superseded(대체됨): [알림 저장은 JPA와 독립 트랜잭션으로 처리한다](<2026.09.17 알림 저장은 JPA와 독립 트랜잭션으로 처리한다.md>). 변경값만 저장하는 모델은 유지하고, upsert 및 과거 데이터 보존 결정을 변경한다.

사용자 결정에 따라 20종 모두 기본 ON으로 한다. 명시적인 수신 거부만 false 행으로 저장하고 수신 허용 복원은 행 삭제로 처리한다.

## Consequences(결과와 영향)

설정 조회 시 전체 액션과 사용자 변경값을 병합해야 하며, 향후 그룹 변경 API는 그룹 소속 액션에 동일한 변경 규칙을 한 트랜잭션으로 적용해야 한다. 기본값 자체를 변경하면 행이 없는 사용자의 수신 여부도 바뀐다. 과거에 기본값과 같아 저장하지 않았던 명시적 선택은 복원할 수 없으므로 기본값 변경은 사용자 영향 검토가 필요하다.

그룹은 DB에 중복 저장하지 않는다. 액션 코드 변경은 설정 및 알림 데이터 마이그레이션을 동반해야 한다. 기존 `type/category` DB 컬럼은 과거 값 보존을 위해 nullable로 전환하고 엔티티에서 제거한다. 신규 쓰기는 해당 컬럼을 채우지 않으며 구 enum을 코드에 남기지 않는다. 물리 컬럼 삭제는 별도 보관 정책 결정 후 수행한다. 스키마를 먼저 적용하고 새 조회 계약에 맞춰 클라이언트를 전환해야 한다.
