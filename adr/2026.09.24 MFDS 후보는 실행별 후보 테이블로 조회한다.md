# MFDS 후보는 실행별 후보 테이블로 조회한다

- Decision Date(결정일): 2026.09.24
- Scope(대상): Admin MFDS 매칭 실행, 후보 조회, 신고 상세, 관리자 확정

## Context(배경)

MFDS 수집기는 실행·후보·근거 테이블과 신고의 후보 1~3번 컬럼을 함께 기록한다. Admin API는 고정 컬럼만 갱신해 최신 후보와 과거 `matching_run_id`가 불일치할 수 있었다. 후보를 10개로 늘리기 위해 순위별 컬럼을 추가하면 이 중복이 커진다. 기존 후보 테이블의 순위와 유일 키는 이미 10개를 수용한다.

## Decision(결정)

Admin API는 `mfds_declarations`의 주류·증류소·지역 후보 컬럼을 매핑하거나 참조하지 않는다. POST는 신고를 잠금 조회하고, 새 `mfds_matching_runs`, `mfds_matching_candidates`, `mfds_matching_evidence`를 저장한 뒤 신고의 실행 ID·버전·시각을 같은 트랜잭션에서 갱신한다. 확정값은 재계산으로 바꾸지 않는다. 후보가 없어도 새로운 완료 실행을 남긴다.

후보 조회·신고 상세·CANDIDATE 판정은 신고 ID와 최신 실행 ID에 해당하는 후보를 사용한다. 실행이 완료 상태이고 신고의 계산 버전과 일치해야 한다. 실행이 없거나 버전이 어긋나면 빈 후보를 반환하고 고정 컬럼으로 대체하지 않는다. 과거 Admin 결과의 불일치는 재계산으로 해결하며 GET은 데이터를 이관하거나 계산하지 않는다.

주류 후보는 0.4 이상 상위 10개, 증류소·지역은 각각 상위 3개다. v2 점수는 소수점 4자리로 계산·정렬·저장·응답한다. 수집기의 기존 raw score는 원래 척도로 반환하며 서로 다른 버전의 점수를 합쳐 순위를 만들지 않는다.

v2는 원문을 우선해 브랜드와 제품 속성을 비교한다. 브랜드·숙성·배치·캐스크·연도가 명확하게 다르면 점수를 제한하고, 누락은 UNKNOWN으로 구별한다. 원문·필드 충돌과 제품명이 부족한 후보에는 reviewRequired를 표시한다. 이 값은 자동 확정 승인을 뜻하지 않는다.

Admin의 요소별 점수와 검토 상태는 기존 evidence의 `ADMIN_SCORE_DETAIL_V2` 항목 input_value에 JSON으로 보존한다. 각 속성의 비교 결과도 별도 evidence로 저장한다. 비교 판정은 rule_code에 기록하며 합산 기여도가 아닌 판정 근거이므로 weight는 0이다. 수집기의 기존 evidence_strength와 척도를 혼합하지 않도록 Admin의 evidence_strength도 0으로 둔다.

## Status(상태)

Accepted(승인됨).

## Consequences(결과와 영향)

후보 개수 변경에 스키마 변경이 필요 없으며 재계산 이력과 당시 점수 근거가 남는다. 조회 시 새로운 계산을 하지 않는다. 후보 저장 실패 시 실행과 최신 연결도 롤백된다. 삭제된 카탈로그 후보도 저장된 이름과 점수로 설명할 수 있다.

현재 확정값과 관리자 선택 이력은 유지한다. 증류소·지역이 먼저 확정된 신고 및 신규 주류 등록 초기값을 보존한다. 기존 선택 이력의 run_id는 반복 관리자 확정 기록을 허용하기 위해 기존처럼 null로 유지한다.

V22 마이그레이션은 신고의 주류·증류소·지역 후보 1~3번 ID·점수 컬럼 18개를 삭제하고 상세 조회 뷰를 다시 정의한다. 기존 슬롯을 후보 테이블로 이관하지 않으며 실행 이력이 없으면 재계산한다. 확정 ID와 이름 정제용 후보 필드는 유지한다. 마이그레이션 적용 전 외부 수집기·정제기·대시보드에서 고정 컬럼 참조를 제거한 버전이 배포되어야 한다. 로컬 소스 변경만으로 이 선행 조건이 충족됐다고 판단하지 않는다. 수집기의 Stage A/B 결과 테이블을 Admin 실행이 채우지는 않는다. Admin 실행은 후보·근거 테이블에 보존하며 수집기 전용 결과 화면이 Admin 실행까지 지원하려면 별도 대응이 필요하다.

브랜드·제품명 추출은 규칙 기반이며 별칭과 한글·영문 표기 차이를 모두 해결하지는 않는다. 점수는 정답 확률이 아니다. 제품명이 부족한 신고는 사람이 확인해야 한다.
