# ADR: API 문서는 springdoc 런타임 OpenAPI endpoint로 제공하고 RestDocs·AsciiDoc·Antora는 제거한다

- Decision Date(결정일): 2026.08.03 (product-api 2026.07.26, admin-api와 레거시 제거 2026.08.03)
- Scope(대상): `bottlenote-product-api`, `bottlenote-admin-api`, `docs/`, `.github/workflows`
- Related PRs(관련 PR): `bottle-note/bottle-note-api-server#693`
- Original Plan(원본 계획): `plan/openapi-annotation-docs.md`, `plan/complete/admin-openapi-and-legacy-docs-removal.md`, `antora-documentation-migration.md`(대체됨) (git 히스토리)

## Context(배경)

문서 체계가 RestDocs 테스트 41개 → asciidoc 92개 → Antora 정적 사이트였다. 세 단계를 사람이 동기화해야 했고 산출물이 HTML이라 기계가 읽을 수 없어 클라이언트 코드 생성이나 API 테스트 도구를 붙일 수 없었다. main에 `restdocs-api-spec` 파일럿이 있었지만 endpoint마다 문서화 테스트를 유지해야 하고 Mockito 의존(레이어 표준 10 위반)이 필요했다. 실측에서 `PUT /api/v1/picks` 등이 `GlobalResponse`를 이중으로 감싸고 있던 결함도 이 과정에서 잡았다.

## Decision(결정)

- product-api는 `GET /openapi.product.json`, admin-api는 `GET /admin/api/v1/openapi.admin.json`으로 OpenAPI 3.1 스펙을 런타임에 제공한다. springdoc 2.8.x(Spring Boot 3.x 지원 라인)를 쓰고 swagger-ui는 비활성화한다. 빌드 타임 JSON 산출은 하지 않는다.
- 두 문서 URL은 인증 없이 PUBLIC이지만 일반 API CORS와 분리된 문서 전용 CORS 정책을 쓴다. 허용 Origin은 `https://bottle-note.github.io`뿐이며 임의 Origin에는 permissive 헤더를 반환하지 않는다.
- 문서 어노테이션은 컨트롤러 밖 `{domain}.controller.docs.*ApiDocs` 메타 어노테이션으로 격리한다. 태그·summary·description은 화면 노출을 전제로 한국어 자연어 문장으로 쓴다.
- `GlobalResponse.data`가 `Object`라 응답 스키마는 `OperationCustomizer`(`GlobalResponseSchemaCustomizer`)가 공통 형식으로 감싼다. 감쌀지 여부는 컨트롤러 선언 반환 타입으로 판정한다. `ResponseEntity<GlobalResponse>`는 감싸고 `ResponseEntity<NonceResponse>`처럼 구체 타입은 감싸지 않는다. 예외 목록을 코드 밖에 두지 않는다.
- 컨트롤러의 `ResponseEntity<?>` 와일드카드 반환을 금지하는 ArchUnit 규칙을 둔다. 제네릭 소거로 바이트코드와 응답은 같으므로 API 계약 변경이 아니다.
- `OpenApiSpecQualityTest`가 fallback 태그, summary 누락, 메서드명과 같은 summary, 빈 정상 응답 스키마를 전수 검사한다.
- Admin 문서가 대체 가능함을 검증한 뒤 Product/Admin의 RestDocs 테스트, AsciiDoc 원본, Antora 사이트, 관련 빌드·CI를 제거한다.

### Rejected Alternatives(선택하지 않은 대안)

- `restdocs-api-spec` 확장: 테스트 기반이라 유지 비용이 같고 Mockito를 요구한다.
- Scalar UI 동시 도입: `springdoc-openapi-starter-webmvc-scalar`와 WebJar 로컬 서빙까지 확인했으나 범위 밖으로 뒀다.
- 두 체계 영구 공존: 전환기에만 의도적으로 공존시키고 검증 후 레거시를 제거했다.

## Status(상태)

Accepted(승인됨)

- Implementation Record(적용 기록): 적용됨

## Consequences(결과와 영향)

- 에러 응답(4xx/5xx) 문서화는 product의 전역 오류 문서화 정책에 맞춰 제공하되 런타임 예외 계약은 바꾸지 않는다.
- `bottle-note/workspace`의 `docs/apis.json` Admin URL 교체는 별도 저장소 작업이다.
- OpenAPI JSON 자체는 `@SecurityPolicy` PUBLIC을 명시해야 한다(2026.06.04 ADR).
